# Garito para escritorio

Descargas de la app de escritorio de [Garito](https://www.garito.app), el tablero Kanban que se organiza solo.

| Sistema | Descarga |
|---|---|
| Windows 10 y 11 | [Garito-Setup.exe](https://github.com/ArkaitzL/garito-releases/releases/latest/download/Garito-Setup.exe) |
| Linux (cualquier distribución) | [Garito.AppImage](https://github.com/ArkaitzL/garito-releases/releases/latest/download/Garito.AppImage) |
| Ubuntu, Debian y derivadas | [Garito.deb](https://github.com/ArkaitzL/garito-releases/releases/latest/download/Garito.deb) |

La app se actualiza sola cuando hay una versión nueva.

- **Windows:** si aparece el aviso de que la app no es conocida, pulsa «Más información» y «Ejecutar de todas formas».
- **AppImage:** dale permiso de ejecución (`chmod +x Garito.AppImage`) y ábrela.

Este repositorio solo contiene las versiones publicadas.
